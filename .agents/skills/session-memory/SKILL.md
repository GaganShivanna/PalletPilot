# Session Memory

Goal: Prevent repeated rediscovery of project knowledge.

## Retrieval

Consult existing Muse memory before creating duplicate notes.

Load only memory related to the current task.

Verify technical claims against current source code
when they might have become outdated.

## What to remember

- Architecture and important dependencies
- Why significant decisions were made
- Known bugs and their root causes
- Non-obvious codebase conventions
- Important unfinished tasks
- Validated solutions to recurring problems

## What not to remember

- Full conversation transcripts
- Entire source files
- Routine tool output
- Temporary debugging noise
- Secrets, tokens, or credentials

## Maintenance

- Keep notes short and searchable.
- Link findings to actual file paths.
- Update or supersede outdated notes.
- Separate confirmed facts from hypotheses.
- Use native Muse memory when appropriate.

## End-of-task review

Record only reusable information.
Do not write memory when nothing meaningful changed.
